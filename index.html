What is a function?

A reusable block of code designed to perform a specific task. It is executed when called, can take inputs (arguments), and can return an output (a value).

# Function definition ----
add_two_values <- function(a, b) {
  
  c <- a + b
  return(c)
}


# Function call ----
add_two_values(3, 4)
## [1] 7

Anatomy of a function

function_name <- function(arg1, arg2 = default_value) {

  # Body of the function that builds
  # the result `output`

  return(output)
}

Key components

  • Definition - A function is defined using the function() keyword
  • Name - A function can have a meaningful and descriptive name
  • Arguments (inputs) - A function can take zero, one or multiple arguments
  • Body - The function body contains the instructions that are executed when the function is called
  • Return value (output) - A function returns a value, either explicitly using return() or implicitly through the last evaluated expression

Function workflow

  1. Create an R script1
    Create a .R file in the R/ directory
file.create("R/add_two_values.R")

  1. Define the function
    Write the function definition
add_two_values <- function(a, b) {
  a + b
}

  1. Source the file
    Load the function definition into R
source("R/add_two_values.R")

  1. Call the function
    Use the function in your script
add_two_values(1050, 3234)

  1. You can define one function per .R file or group multiple functions in a single .R file

The R/ directory

Important

  Do not rename the R/ folder

  It should contain function definitions only, not analysis or scripts

  All function definitions should be stored in the R/ folder

Function arguments

Arguments define the inputs a function can receive.

  1. Required arguments: must be provided when calling the function.
add_two_values <- function(a, b) {
  a + b
}

add_two_values(5, 10)
  1. Default arguments: have predefined values and can be omitted.
add_two_values <- function(a, b = 8) {
  a + b
}

add_two_values(5)
  1. Argument matching: arguments can be passed by position or by name.
add_two_values(10, 5)
add_two_values(b = 5, a = 10)

Documenting a function

Why document functions?

  • Explain the purpose of a function

  • Describe its arguments and return values

  • Provide usage examples

  • Improve readability and maintainability

roxygen2

  • An R package used to document functions

  • Documentation is written directly above function definitions

  • Syntax: #' @field value

#' Add two values
#'
#' Adds two numeric values and returns their sum.
#'
#' @param a A numeric value of length 1.
#' @param b A numeric value of length 1.
#'
#' @return A numeric value representing the sum 
#'   of `a` and `b`.
#'
#' @examples
#' add_two_values(2, 3)

add_two_values <- function(a, b) {
  a + b
}
